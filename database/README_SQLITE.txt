Bancos SQLite usados pelo sistema:

- database/subbots.sqlite -> cadastro/status/logs dos subbots.
- database/kaoruko_ai.sqlite -> memória, histórico e cache de internet da Kaoruko IA.
- database/grupos/configuracoes.sqlite -> configurações/atividades dos grupos (tabela group_configs).
- database/KAUROKO-QR/auth_state.sqlite -> sessão do bot principal após conectar.
- database/subbots/sessions/<id>/auth_state.sqlite -> sessão de cada subbot após parear.
